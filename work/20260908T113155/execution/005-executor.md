## Summary

**Root cause found:** `evals/live.py` already parsed and validated a `--stage {intent,narration,end-to-end}` flag and recorded it in the checkpoint, but `run_trial`/`run_suite` never branched on it — every trial, regardless of `--stage`, ran the same legacy tool-loop (`build_agent()` + `ask(agent, deps, question)`). The flag was decorative.

**Files changed:**

- **`evals/live.py`** — Added three genuinely isolated trial runners: `run_intent_trial` (Stage 1 alone — `interpret_intent()`, no tools, no subprocess), `run_narration_trial` (Stage 4 alone — fetches the case's own declared envelope directly, builds an `AnswerView`, calls `narrate()`), and `run_end_to_end_trial` (drives the real new-pipeline `ask(deps, question)`, not the legacy signature). `run_trial`/`run_suite` now dispatch on `stage` to these (default `None` is unchanged legacy behaviour). Extracted the auth/quota-vs-failed-trial classification into a shared `_crashed_trial` helper so that rule can't drift between stages. `select_cases` now filters to cases with a fixed `expected_question_id`/`expected_request` for `--stage narration`. `main()` now passes `stage=args.stage` into `run_suite`. Checkpointing, resumability, `--max-trials` chunking, and completed-trial semantics (`completed_reports`, `aggregate`) were untouched.
- **`evals/graders.py`** — Added `grade_intent`/`grade_intent_question_match` (isolated Stage-1 grading) and `NARRATION_GRADERS`/`grade_case_narration` (the full prose/envelope rule set minus the three graders that judge a decision narration never makes: question/request selection and school resolution).
- **`tests/unit/test_live_tier.py`** — Added offline `FunctionModel`-scripted tests covering: isolation of the intent stage (no tool calls, correct/wrong/refusal classification, crash handling), isolation of the narration stage (grounded pass, ungrounded → harness gate rejection, cases with no fixed envelope are skipped, `select_cases` filtering), and the end-to-end stage running the real pipeline offline through the stub emitter with both stages scripted.
